# Token history

Open **Settings → Usage** and select Codex or Claude Code. View Today, This Week, This Month, and Local History, then explore models, projects, sessions, and daily charts.

## Scope

- Local history covers observable sessions on **this Mac across accounts**. Switching accounts does not reset it.
- Codex and Claude Code histories remain separate. Other providers expose their own limits, credits, spending, or status; they do not gain local session history.
- Missing or deleted logs cannot be reconstructed. A limit percentage is a provider allowance, not a local token count.

## Counting and estimates

Cached input is already part of input: **Total = Input + Output**. It must not be added again. Claude input includes uncached input, cache reads, and cache creation.

API cost estimates use known model pricing and are not subscription bills. When some usage cannot be priced, the interface labels the available subtotal and exclusions. Unknown pricing does not mean zero cost.

For exact import rules and source boundaries, see [usage accounting](../Documentation/USAGE.md) and [Claude accounting](../Documentation/CLAUDE.md#accounting).
