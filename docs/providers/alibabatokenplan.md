# Alibaba Token Plan

**English** · [한국어](../ko/providers/alibabatokenplan.md)

Bailian token-plan usage.

CLI provider ID: `alibabatokenplan`.

## Connect

Use an authenticated Bailian CLI or a signed-in Bailian browser session. Select the token-plan account and region that own the subscription.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `ALIBABA_TOKEN_PLAN_HOST`, `ALIBABA_TOKEN_PLAN_QUOTA_URL`.

Check `coderim usage --provider alibabatokenplan` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/alibaba-token-plan.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
