# xAI

**English** · [한국어](../ko/providers/xai.md)

Team balance and API spending.

CLI provider ID: `xai`.

## Connect

Set XAI_MANAGEMENT_API_KEY and XAI_TEAM_ID for the team whose balance and spending you want to read.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `XAI_MANAGEMENT_API_KEY`, `XAI_TEAM_ID`.

Check `coderim usage --provider xai` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/xai.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
