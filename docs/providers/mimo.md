# Xiaomi MiMo

**English** · [한국어](../ko/providers/mimo.md)

Account balance and token-plan usage.

CLI provider ID: `mimo`.

## Connect

Sign in to Xiaomi MiMo in a supported browser and enable browser-session import.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `MIMO_API_URL`, `MIMO_LOCAL_USAGE_PATH`.

Check `coderim usage --provider mimo` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/mimo.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
