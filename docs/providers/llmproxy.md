# LLM Proxy

**English** · [한국어](../ko/providers/llmproxy.md)

Proxy quotas and usage.

CLI provider ID: `llmproxy`.

## Connect

Provide the proxy API key and base URL for the quota-stats endpoint.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `LLM_PROXY_API_KEY`, `LLM_PROXY_BASE_URL`.

Check `coderim usage --provider llmproxy` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/llm-proxy.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
