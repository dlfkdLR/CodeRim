# Moonshot / Kimi Open Platform

**English** · [한국어](../ko/providers/moonshot.md)

Kimi Open Platform API balance.

Also known as **Kimi API**. The app lists this entry as **Moonshot / Kimi Open Platform**.

CLI provider ID: `moonshot`.

## Connect

Enter the Moonshot/Kimi Open Platform API key. Choose the correct region for the account balance endpoint.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `MOONSHOT_API_KEY`, `MOONSHOT_KEY`, `MOONSHOT_REGION`.

Check `coderim usage --provider moonshot` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/moonshot.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
