# IBM Bob

**English** · [한국어](../ko/providers/ibmbob.md)

Bobcoin usage.

CLI provider ID: `ibmbob`.

## Connect

Enter the IBM Bob API key for the subscription team whose Bobcoin usage you want to monitor.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `BOBSHELL_API_KEY`.

Check `coderim usage --provider ibmbob` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
