## Connect

Sign in to the Abacus account in a supported browser and enable browser-session import.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

Check `coderim usage --provider abacus` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
