# Neuralwatt

**English** · [한국어](../ko/providers/neuralwatt.md)

API quota usage.

CLI provider ID: `neuralwatt`.

## Connect

Enter a Neuralwatt API key with access to quota and usage data.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `NEURALWATT_API_KEY`, `NEURALWATT_API_URL`.

Check `coderim usage --provider neuralwatt` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
