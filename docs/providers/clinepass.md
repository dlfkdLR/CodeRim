# ClinePass

**English** · [한국어](../ko/providers/clinepass.md)

Five-hour, weekly, and monthly limits.

CLI provider ID: `clinepass`.

## Connect

Enter a ClinePass API key in Connection settings. The subscription must expose the usage-limits endpoint.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

Check `coderim usage --provider clinepass` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
