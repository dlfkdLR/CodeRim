# Deepgram

**English** · [한국어](../ko/providers/deepgram.md)

Speech and API usage metrics.

CLI provider ID: `deepgram`.

## Connect

Enter a Deepgram API key. Set DEEPGRAM_PROJECT_ID when the account has multiple projects or discovery cannot select one.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `DEEPGRAM_API_KEY`, `DEEPGRAM_API_URL`, `DEEPGRAM_PROJECT_ID`.

Check `coderim usage --provider deepgram` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/deepgram.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
