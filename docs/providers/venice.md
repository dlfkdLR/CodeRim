# Venice

DIEM and USD balances.

CLI provider ID: `venice`.

## Connect

Enter a Venice API key for the account balance query.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `VENICE_API_KEY`, `VENICE_KEY`.

Check `coderim usage --provider venice` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
