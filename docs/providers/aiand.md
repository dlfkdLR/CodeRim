# ai&

**English** · [한국어](../ko/providers/aiand.md)

Spending over the past 30 days.

CLI provider ID: `aiand`.

## Connect

Enter an ai& API key with access to request logs used for spending totals.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `AIAND_API_KEY`.

Check `coderim usage --provider aiand` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/aiand.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
