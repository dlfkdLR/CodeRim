# T3 Chat

**English** · [한국어](../ko/providers/t3chat.md)

Chat usage allowances.

CLI provider ID: `t3chat`.

## Connect

Sign in to T3 Chat in a supported browser and enable browser-session import for this provider.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

Check `coderim usage --provider t3chat` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/t3chat.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
