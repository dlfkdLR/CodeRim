## Connect

Enter a Kilo API token or sign in to the Kilo CLI so that its existing auth file is available.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `KILO_API_KEY`.

Check `coderim usage --provider kilo` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
