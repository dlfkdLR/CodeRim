# Manus

**English** · [한국어](../ko/providers/manus.md)

Credit balance and daily allowances.

CLI provider ID: `manus`.

## Connect

Import the signed-in Manus browser session or supply its session_id cookie as a manual session.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `MANUS_COOKIE`, `MANUS_SESSION_TOKEN`.

Check `coderim usage --provider manus` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/manus.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
