# DeepSeek

**English** · [한국어](../ko/providers/deepseek.md)

API credit balance.

CLI provider ID: `deepseek`.

## Connect

Enter a DeepSeek API key for balance queries. A separate platform session can expose additional usage details.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `DEEPSEEK_API_KEY`, `DEEPSEEK_KEY`, `DEEPSEEK_PLATFORM_TOKEN`, `DEEPSEEK_USER_TOKEN`.

Check `coderim usage --provider deepseek` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
