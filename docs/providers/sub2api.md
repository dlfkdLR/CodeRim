# sub2api

**English** · [한국어](../ko/providers/sub2api.md)

Gateway quotas and wallet balance.

CLI provider ID: `sub2api`.

## Connect

Provide the group API key and base URL of your sub2api gateway.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `SUB2API_API_KEY`, `SUB2API_BASE_URL`.

Check `coderim usage --provider sub2api` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/sub2api.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
