# Vertex AI

**English** · [한국어](../ko/providers/vertexai.md)

Google Cloud quota usage.

CLI provider ID: `vertexai`.

## Connect

Set up Google Cloud application-default credentials with gcloud for the relevant project. The account needs permission to read the project quota metrics.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CLOUDSDK_CORE_PROJECT`, `GCLOUD_PROJECT`, `GOOGLE_CLOUD_PROJECT`.

Check `coderim usage --provider vertexai` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/vertexai.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
