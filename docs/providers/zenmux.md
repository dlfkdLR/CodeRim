# ZenMux

**English** · [한국어](../ko/providers/zenmux.md)

Quota windows and prepaid balance.

CLI provider ID: `zenmux`.

## Connect

Enter a ZenMux Management API key for quota and balance queries.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `ZENMUX_MANAGEMENT_API_KEY`.

Check `coderim usage --provider zenmux` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
