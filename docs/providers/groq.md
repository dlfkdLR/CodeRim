# Groq

**English** · [한국어](../ko/providers/groq.md)

Console usage and spending.

Also known as **GroqCloud**. The app lists this entry as **Groq**.

CLI provider ID: `groq`.

## Connect

Use a signed-in Groq console session for spending and usage. Enterprise accounts can use the Prometheus API-key source when available.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `GROQ_API_KEY`, `GROQ_SESSION_JWT`, `GROQ_SESSION_TOKEN`, `GROQ_STYTCH_PUBLIC_TOKEN`, `GROQ_STYTCH_URL`.

Check `coderim usage --provider groq` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/groq.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
