# Poe

**English** · [한국어](../ko/providers/poe.md)

Point balance and usage history.

CLI provider ID: `poe`.

## Connect

Enter a Poe API key with access to point balance and recent usage.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `POE_API_KEY`.

Check `coderim usage --provider poe` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
