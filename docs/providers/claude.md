# Claude Code

Local token history and status-line usage limits.

CLI provider ID: `claude`.

## Connect

1. Run `claude` and sign in to the official Claude CLI.
2. Open **Settings → Providers → Claude Code Details**, enable the integration, and add the signed-in account.
3. Complete a Claude Code response so its status-line integration can send five-hour and weekly limit data.

## Check the reading

Hover the provider in the notch, or read the latest app snapshot with `coderim usage --provider claude` after [installing the CLI](../cli.md). Keep CodeRim running for fresh readings.

Limits update when Claude Code sends a status-line update. A last-known reading can require another completed response. See the [Claude integration reference](../../Documentation/CLAUDE.md) and [saved accounts](../accounts.md).
