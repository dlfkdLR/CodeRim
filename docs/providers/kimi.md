# Kimi Code

**English** · [한국어](../ko/providers/kimi.md)

Kimi Code quotas and rate limits.

Also known as **Kimi**. The app lists this entry as **Kimi Code**.

CLI provider ID: `kimi`.

## Connect

Use a Kimi Code API key or the supported Kimi session token. This entry is for Kimi Code; API account balances use Moonshot.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `KIMI_AUTH_TOKEN`, `KIMI_CODE_API_KEY`, `KIMI_CODE_BASE_URL`, `KIMI_CODE_HOME`, `KIMI_CODE_OAUTH_HOST`, `KIMI_OAUTH_HOST`.

Check `coderim usage --provider kimi` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/kimi.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
