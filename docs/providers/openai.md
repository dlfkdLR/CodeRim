# OpenAI

**English** · [한국어](../ko/providers/openai.md)

API usage, spending, and available credits.

CLI provider ID: `openai`.

## Connect

Use an OpenAI Admin API key for organization usage and costs. A regular API key only supports the legacy balance source when the account exposes it.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `OPENAI_ADMIN_KEY`, `OPENAI_API_KEY`, `OPENAI_PROJECT_ID`.

Check `coderim usage --provider openai` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/openai.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
