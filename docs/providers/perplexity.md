# Perplexity

**English** · [한국어](../ko/providers/perplexity.md)

Account usage credits.

CLI provider ID: `perplexity`.

## Connect

Sign in to Perplexity in a supported browser, or supply its manual session token or Cookie header.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `PERPLEXITY_COOKIE`, `PERPLEXITY_SESSION_TOKEN`.

Check `coderim usage --provider perplexity` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/perplexity.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
