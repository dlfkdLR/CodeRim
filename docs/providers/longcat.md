# LongCat

**English** · [한국어](../ko/providers/longcat.md)

Account quota windows.

CLI provider ID: `longcat`.

## Connect

Supply the signed-in LongCat Cookie header through LONGCAT_MANUAL_COOKIE in Additional provider settings.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `LONGCAT_MANUAL_COOKIE`.

Check `coderim usage --provider longcat` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/longcat.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
