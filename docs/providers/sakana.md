Quota windows and available credits.

CLI provider ID: `sakana`.

## Connect

Provide the Cookie header for a signed-in Sakana account in the manual session field.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `SAKANA_COOKIE`.

Check `coderim usage --provider sakana` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
