# OpenCode

**English** · [한국어](../ko/providers/opencode-zen.md)

Zen workspace subscription usage.

Also known as **OpenCode Zen**. The app lists this entry as **OpenCode**.

CLI provider ID: `opencode-zen`.

## Connect

Sign in to the OpenCode workspace in your browser. Enable browser-session import for this provider, or supply its session cookie. This is the Zen entry; the Go plan has a separate provider.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CODEXBAR_OPENCODE_WORKSPACE_ID`, `OPENCODE_API_KEY`.

Check `coderim usage --provider opencode-zen` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/opencode.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
