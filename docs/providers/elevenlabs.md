# ElevenLabs

**English** · [한국어](../ko/providers/elevenlabs.md)

Subscription credits and usage.

CLI provider ID: `elevenlabs`.

## Connect

Enter an ElevenLabs API key with access to the subscription usage fields.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `ELEVENLABS_API_KEY`, `ELEVENLABS_API_URL`, `XI_API_KEY`.

Check `coderim usage --provider elevenlabs` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
