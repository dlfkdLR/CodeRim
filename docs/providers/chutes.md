# Chutes

**English** · [한국어](../ko/providers/chutes.md)

Subscription usage and quota windows.

CLI provider ID: `chutes`.

## Connect

Enter a Chutes API key for the subscription usage endpoints.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CHUTES_API_KEY`, `CHUTES_API_URL`.

Check `coderim usage --provider chutes` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
