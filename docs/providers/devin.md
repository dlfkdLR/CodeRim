# Devin

**English** · [한국어](../ko/providers/devin.md)

Account quota windows.

CLI provider ID: `devin`.

## Connect

Use the Devin browser session or supply the account bearer token. If required, set the organization in Additional provider settings.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `DEVIN_AUTHORIZATION`, `DEVIN_BEARER_TOKEN`, `DEVIN_ORG`, `DEVIN_ORGANIZATION`.

Check `coderim usage --provider devin` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/devin.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
