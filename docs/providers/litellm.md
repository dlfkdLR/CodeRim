# LiteLLM

**English** · [한국어](../ko/providers/litellm.md)

Key and team spending budgets.

CLI provider ID: `litellm`.

## Connect

Provide a LiteLLM virtual key and proxy base URL. Budget visibility depends on the permissions assigned to the key.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `LITELLM_API_KEY`, `LITELLM_BASE_URL`.

Check `coderim usage --provider litellm` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/litellm.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
