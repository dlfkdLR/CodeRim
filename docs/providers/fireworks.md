# Fireworks

**English** · [한국어](../ko/providers/fireworks.md)

Account spending over the past 30 days.

CLI provider ID: `fireworks`.

## Connect

Provide the Fireworks API key and set FIREWORKS_ACCOUNT_SLUG in Additional provider settings. The account slug is required for the billing query.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `FIREWORKS_ACCOUNT_SLUG`, `FIREWORKS_API_KEY`, `FIREWORKS_KEY`.

Check `coderim usage --provider fireworks` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/fireworks.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
