# Zed

**English** · [한국어](../ko/providers/zed.md)

Editor plan and usage allowances.

CLI provider ID: `zed`.

## Connect

Sign in through the Zed editor. CodeRim uses the editor session stored in this Mac's Keychain.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

Check `coderim usage --provider zed` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/zed.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
