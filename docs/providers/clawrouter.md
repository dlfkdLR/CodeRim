# ClawRouter

**English** · [한국어](../ko/providers/clawrouter.md)

Router spending and monthly budgets.

CLI provider ID: `clawrouter`.

## Connect

Provide the router API key and base URL for the monthly budget and usage endpoints.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CLAWROUTER_API_KEY`, `CLAWROUTER_BASE_URL`.

Check `coderim usage --provider clawrouter` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/clawrouter.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
