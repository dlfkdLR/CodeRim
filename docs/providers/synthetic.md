# Synthetic

**English** · [한국어](../ko/providers/synthetic.md)

API quota windows.

CLI provider ID: `synthetic`.

## Connect

Enter a Synthetic API key for the account whose quota you want to monitor.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `SYNTHETIC_API_KEY`.

Check `coderim usage --provider synthetic` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/synthetic.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
