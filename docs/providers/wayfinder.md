# Wayfinder

**English** · [한국어](../ko/providers/wayfinder.md)

Local gateway health and route statistics.

CLI provider ID: `wayfinder`.

## Connect

Set WAYFINDER_GATEWAY_URL to the running local gateway. This entry monitors router health and statistics, not an account subscription quota.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `WAYFINDER_GATEWAY_URL`.

Check `coderim usage --provider wayfinder` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
