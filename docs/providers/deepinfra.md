# DeepInfra

**English** · [한국어](../ko/providers/deepinfra.md)

Balance, spending, and configured limits.

CLI provider ID: `deepinfra`.

## Connect

Enter a DeepInfra API key with access to the account billing information.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `DEEPINFRA_API_KEY`, `DEEPINFRA_TOKEN`.

Check `coderim usage --provider deepinfra` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/deepinfra.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
