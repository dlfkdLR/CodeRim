# Ollama Local

Loaded models and local memory usage.

CLI provider ID: `ollama-local`.

## Connect

1. Start the local Ollama runtime and load a model.
2. Add **Ollama Local** in **Settings → Providers → Add Provider**.
3. Refresh to inspect loaded models and memory use. This provider has no cloud subscription quota.

## Check the reading

Hover the provider in the notch, or read the latest app snapshot with `coderim usage --provider ollama-local` after [installing the CLI](../cli.md). Keep CodeRim running for fresh readings.

An empty model list means no models are currently loaded; it does not mean a cloud quota has been exhausted.
