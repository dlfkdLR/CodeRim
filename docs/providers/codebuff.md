# Codebuff

**English** · [한국어](../ko/providers/codebuff.md)

Credits and weekly limits.

CLI provider ID: `codebuff`.

## Connect

Enter a Codebuff API token or sign in to its CLI so the supported local credentials file is available.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CODEBUFF_API_KEY`, `CODEBUFF_API_URL`.

Check `coderim usage --provider codebuff` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/codebuff.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
