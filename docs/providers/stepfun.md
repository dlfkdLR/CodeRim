# StepFun

**English** · [한국어](../ko/providers/stepfun.md)

Step Plan limits.

CLI provider ID: `stepfun`.

## Connect

Set STEPFUN_USERNAME and STEPFUN_PASSWORD under Additional provider settings, or provide an existing Oasis-Token. Use the account that owns the Step Plan.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `STEPFUN_PASSWORD`, `STEPFUN_TOKEN`, `STEPFUN_USERNAME`.

Check `coderim usage --provider stepfun` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/stepfun.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
