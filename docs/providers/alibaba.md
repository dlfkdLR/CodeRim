# Alibaba

**English** · [한국어](../ko/providers/alibaba.md)

Alibaba Coding Plan quotas.

Also known as **Alibaba Coding Plan**. The app lists this entry as **Alibaba**.

CLI provider ID: `alibaba`.

## Connect

Sign in to Model Studio/Bailian and import that browser session, or provide a manual Cookie header. API-key access depends on the account and region.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `ALIBABA_CODING_PLAN_API_KEY`, `ALIBABA_QWEN_API_KEY`, `DASHSCOPE_API_KEY`, `ALIBABA_CODING_PLAN_COOKIE`, `ALIBABA_CODING_PLAN_HOST`, `ALIBABA_CODING_PLAN_QUOTA_URL`, `ALIBABA_CODING_PLAN_REQUIRE_PROVIDER_ENDPOINT_OVERRIDES`.

Check `coderim usage --provider alibaba` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/alibaba-coding-plan.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
