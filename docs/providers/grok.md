# Grok

Credits and usage through Grok CLI.

CLI provider ID: `grok`.

## Connect

1. Sign in to Grok CLI on this Mac.
2. Add **Grok** in **Settings → Providers → Add Provider**.
3. Refresh to load the available credits and usage. This is separate from the **xAI** platform API provider.

## Check the reading

Hover the provider in the notch, or read the latest app snapshot with `coderim usage --provider grok` after [installing the CLI](../cli.md). Keep CodeRim running for fresh readings.

A missing reading can mean the session expired, the account lacks the required plan or permissions, or the service did not return a usable value. Reconnect the provider and refresh; missing data is not zero usage.
