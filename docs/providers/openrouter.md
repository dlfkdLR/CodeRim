# OpenRouter

**English** · [한국어](../ko/providers/openrouter.md)

Credit balance and spending.

CLI provider ID: `openrouter`.

## Connect

Enter an OpenRouter API key. Use the management key option only for account data that requires that permission.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `OPENROUTER_API_KEY`, `OPENROUTER_API_URL`, `OPENROUTER_HTTP_REFERER`, `OPENROUTER_MANAGEMENT_API_KEY`, `OPENROUTER_X_TITLE`.

Check `coderim usage --provider openrouter` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/openrouter.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
