# Crof

**English** · [한국어](../ko/providers/crof.md)

Credit balance and available request quotas.

CLI provider ID: `crof`.

## Connect

Enter the Crof API key for the account usage endpoint.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `CROFAI_API_KEY`, `CROF_API_KEY`.

Check `coderim usage --provider crof` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
