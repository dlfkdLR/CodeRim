# Warp

**English** · [한국어](../ko/providers/warp.md)

Request limits and credits.

CLI provider ID: `warp`.

## Connect

Provide the Warp API token for the account whose request limits and credits you want to read.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `WARP_API_KEY`, `WARP_TOKEN`.

Check `coderim usage --provider warp` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
