# Doubao

**English** · [한국어](../ko/providers/doubao.md)

Ark plan usage and request-limit checks.

CLI provider ID: `doubao`.

## Connect

Use an authenticated arkcli session or provide a supported Ark API key. API-key authentication paths may need a billed request.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `ARKCLI_PATH`, `ARK_API_KEY`, `DOUBAO_API_KEY`, `VOLCENGINE_API_KEY`.

### Monitoring charges

These requests can be billed by the provider. Monitoring stays off until you enable **Allow potentially billed monitoring requests** in this provider's settings.

Check `coderim usage --provider doubao` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/doubao.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
