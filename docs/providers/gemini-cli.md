# Gemini

**English** · [한국어](../ko/providers/gemini-cli.md)

Quotas through Gemini CLI credentials.

Also known as **Gemini CLI**. The app lists this entry as **Gemini**.

CLI provider ID: `gemini-cli`.

## Connect

Sign in through Gemini CLI on this Mac. CodeRim uses its existing OAuth credentials to read quota data.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `GEMINI_OAUTH2_JS_PATH`, `GEMINI_OAUTH_CLIENT_ID`, `GEMINI_OAUTH_CLIENT_SECRET`.

Check `coderim usage --provider gemini-cli` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/gemini.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
