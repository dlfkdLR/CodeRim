# Droid

**English** · [한국어](../ko/providers/factory.md)

Factory usage and billing.

Also known as **Factory**. The app lists this entry as **Droid**.

CLI provider ID: `factory`.

## Connect

Use a Factory API key or a supported signed-in Factory browser session. Factory appears as Droid in the CodeRim catalogue.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `FACTORY_API_KEY`.

Check `coderim usage --provider factory` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
