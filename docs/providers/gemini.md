# Antigravity

Model allowances from the local language server.

CLI provider ID: `gemini`.

## Connect

1. Sign in to Antigravity and leave its local language server running.
2. Add **Antigravity** in **Settings → Providers → Add Provider**.
3. Refresh the provider. Gemini CLI credentials belong to the separate **Gemini** entry.

## Check the reading

Hover the provider in the notch, or read the latest app snapshot with `coderim usage --provider gemini` after [installing the CLI](../cli.md). Keep CodeRim running for fresh readings.

A missing reading can mean the session expired, the account lacks the required plan or permissions, or the service did not return a usable value. Reconnect the provider and refresh; missing data is not zero usage.
