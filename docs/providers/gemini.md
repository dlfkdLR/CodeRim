# Antigravity

**English** · [한국어](../ko/providers/gemini.md)

Model allowances from the local language server.

CLI provider ID: `gemini`.

## Connect

1. Sign in to Antigravity and leave its local language server running.
2. Add **Antigravity** in **Settings → Providers → Add Provider**.
3. Refresh the provider. Gemini CLI credentials belong to the separate **Gemini** entry.

Check `coderim usage --provider gemini` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).
