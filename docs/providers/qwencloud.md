# Qwen Cloud

**English** · [한국어](../ko/providers/qwencloud.md)

Individual Token Plan limits.

CLI provider ID: `qwencloud`.

## Connect

Sign in to the individual Qwen Cloud Token Plan. Import the browser session or provide a manual Cookie header.

Follow the [shared connection steps](../providers.md#connect-a-provider) with the source above.

**Additional provider settings:** `QWEN_CLOUD_COOKIE`, `QWEN_CLOUD_HOST`, `QWEN_CLOUD_QUOTA_URL`.

Check `coderim usage --provider qwencloud` ([CLI setup](../cli.md)); see [readings and troubleshooting](../providers.md#readings-and-troubleshooting).

[Pinned source guide](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/qwen-cloud.md); use [CodeRim connection settings](../providers.md#connect-a-provider).
