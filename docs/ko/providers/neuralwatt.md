# Neuralwatt

[English](../../providers/neuralwatt.md) · **한국어**

API 할당량 사용 현황.

CLI 제공업체 ID: `neuralwatt`.

## 연결

한도·사용량 데이터에 접근할 수 있는 Neuralwatt API 키를 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `NEURALWATT_API_KEY`, `NEURALWATT_API_URL`.

`coderim usage --provider neuralwatt`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/neuralwatt.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
