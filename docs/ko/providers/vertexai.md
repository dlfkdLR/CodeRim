# Vertex AI

[English](../../providers/vertexai.md) · **한국어**

Google Cloud 할당량 사용 현황.

CLI 제공업체 ID: `vertexai`.

## 연결

해당 프로젝트에 대해 gcloud로 Google Cloud application-default 자격 증명을 설정합니다. 프로젝트 한도 지표를 읽을 권한이 필요합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `CLOUDSDK_CORE_PROJECT`, `GCLOUD_PROJECT`, `GOOGLE_CLOUD_PROJECT`.

`coderim usage --provider vertexai`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/vertexai.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
