# Deepgram

[English](../../providers/deepgram.md) · **한국어**

음성 및 API 사용량 지표.

CLI 제공업체 ID: `deepgram`.

## 연결

Deepgram API 키를 입력합니다. 프로젝트가 여러 개이거나 자동으로 선택할 수 없으면 DEEPGRAM_PROJECT_ID를 설정합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `DEEPGRAM_API_KEY`, `DEEPGRAM_API_URL`, `DEEPGRAM_PROJECT_ID`.

`coderim usage --provider deepgram`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/deepgram.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
