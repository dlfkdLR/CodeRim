# ZoomMate

[English](../../providers/zoommate.md) · **한국어**

크레딧 사용량.

CLI 제공업체 ID: `zoommate`.

## 연결

로그인된 Chrome 세션 가져오기를 켜거나 상류 연결 안내의 수동 세션 캡처를 사용합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

`coderim usage --provider zoommate`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/zoommate.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
