# Qwen Cloud

[English](../../providers/qwencloud.md) · **한국어**

Individual Token Plan 사용 한도.

CLI 제공업체 ID: `qwencloud`.

## 연결

개인 Qwen Cloud Token Plan에 로그인합니다. 브라우저 세션을 가져오거나 수동 Cookie 헤더를 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `QWEN_CLOUD_COOKIE`, `QWEN_CLOUD_HOST`, `QWEN_CLOUD_QUOTA_URL`.

`coderim usage --provider qwencloud`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/qwen-cloud.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
