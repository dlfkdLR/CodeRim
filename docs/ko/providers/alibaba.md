# Alibaba

[English](../../providers/alibaba.md) · **한국어**

Alibaba Coding Plan 할당량.

**Alibaba Coding Plan**라는 이름으로도 알려져 있습니다. 앱에는 **Alibaba**로 표시됩니다.

CLI 제공업체 ID: `alibaba`.

## 연결

Model Studio/Bailian에 로그인한 브라우저 세션을 가져오거나 수동 Cookie 헤더를 입력합니다. API 키 접근 여부는 계정·지역에 따라 다릅니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `ALIBABA_CODING_PLAN_API_KEY`, `ALIBABA_QWEN_API_KEY`, `DASHSCOPE_API_KEY`, `ALIBABA_CODING_PLAN_COOKIE`, `ALIBABA_CODING_PLAN_HOST`, `ALIBABA_CODING_PLAN_QUOTA_URL`, `ALIBABA_CODING_PLAN_REQUIRE_PROVIDER_ENDPOINT_OVERRIDES`.

`coderim usage --provider alibaba`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/alibaba-coding-plan.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
