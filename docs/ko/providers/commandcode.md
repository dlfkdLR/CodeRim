# Command Code

[English](../../providers/commandcode.md) · **한국어**

계정 크레딧 사용량.

CLI 제공업체 ID: `commandcode`.

## 연결

1. 이 Mac에서 Command Code로 로그인합니다.
2. **Settings → Providers → Add Provider**에서 **Command Code**를 추가합니다.
3. 제공업체를 새로고침합니다. CodeRim은 Command Code가 `~/.commandcode/auth.json`에 저장한 계정을 읽습니다.

`coderim usage --provider commandcode`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.
