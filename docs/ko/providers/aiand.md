# ai&

[English](../../providers/aiand.md) · **한국어**

최근 30일간 지출.

CLI 제공업체 ID: `aiand`.

## 연결

지출 합계에 사용하는 요청 로그에 접근할 수 있는 ai& API 키를 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `AIAND_API_KEY`.

`coderim usage --provider aiand`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/aiand.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
