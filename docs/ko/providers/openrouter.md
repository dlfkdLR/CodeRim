# OpenRouter

[English](../../providers/openrouter.md) · **한국어**

크레딧 잔액과 지출.

CLI 제공업체 ID: `openrouter`.

## 연결

OpenRouter API 키를 입력합니다. 관리 키 옵션은 해당 권한이 필요한 계정 데이터에만 사용합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `OPENROUTER_API_KEY`, `OPENROUTER_API_URL`, `OPENROUTER_HTTP_REFERER`, `OPENROUTER_MANAGEMENT_API_KEY`, `OPENROUTER_X_TITLE`.

`coderim usage --provider openrouter`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/openrouter.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
