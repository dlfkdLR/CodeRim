# StepFun

[English](../../providers/stepfun.md) · **한국어**

Step Plan 사용 한도.

CLI 제공업체 ID: `stepfun`.

## 연결

Additional provider settings에 STEPFUN_USERNAME과 STEPFUN_PASSWORD를 설정하거나 기존 Oasis-Token을 입력합니다. Step Plan을 소유한 계정을 사용합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `STEPFUN_PASSWORD`, `STEPFUN_TOKEN`, `STEPFUN_USERNAME`.

`coderim usage --provider stepfun`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/stepfun.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
