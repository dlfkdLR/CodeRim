# LiteLLM

[English](../../providers/litellm.md) · **한국어**

키별 및 팀별 지출 예산.

CLI 제공업체 ID: `litellm`.

## 연결

LiteLLM 가상 키와 프록시 기본 URL을 입력합니다. 예산 표시 여부는 키 권한에 따라 다릅니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `LITELLM_API_KEY`, `LITELLM_BASE_URL`.

`coderim usage --provider litellm`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/litellm.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
