# Amp

[English](../../providers/amp.md) · **한국어**

CLI 사용량과 계정 크레딧.

CLI 제공업체 ID: `amp`.

## 연결

Amp CLI에 로그인하거나 지원 API 토큰을 입력하거나 브라우저 세션 대체 소스를 켭니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `AMP_API_KEY`.

`coderim usage --provider amp`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/amp.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
