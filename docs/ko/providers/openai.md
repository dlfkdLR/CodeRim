# OpenAI

[English](../../providers/openai.md) · **한국어**

API 사용량, 지출, 사용 가능한 크레딧.

CLI 제공업체 ID: `openai`.

## 연결

조직 사용량·비용에는 OpenAI Admin API 키를 사용합니다. 일반 API 키는 계정이 제공하는 경우에만 이전 잔액 소스를 지원합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `OPENAI_ADMIN_KEY`, `OPENAI_API_KEY`, `OPENAI_PROJECT_ID`.

`coderim usage --provider openai`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/openai.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
