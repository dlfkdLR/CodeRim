# xAI

[English](../../providers/xai.md) · **한국어**

팀 잔액과 API 지출.

CLI 제공업체 ID: `xai`.

## 연결

잔액·지출을 읽을 팀의 XAI_MANAGEMENT_API_KEY와 XAI_TEAM_ID를 설정합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `XAI_MANAGEMENT_API_KEY`, `XAI_TEAM_ID`.

`coderim usage --provider xai`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/xai.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
