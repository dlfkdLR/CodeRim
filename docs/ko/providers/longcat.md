# LongCat

[English](../../providers/longcat.md) · **한국어**

계정의 기간별 할당량.

CLI 제공업체 ID: `longcat`.

## 연결

Additional provider settings의 LONGCAT_MANUAL_COOKIE에 로그인된 LongCat Cookie 헤더를 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `LONGCAT_MANUAL_COOKIE`.

`coderim usage --provider longcat`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/longcat.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
