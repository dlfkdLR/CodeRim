# Warp

[English](../../providers/warp.md) · **한국어**

요청 한도와 크레딧.

CLI 제공업체 ID: `warp`.

## 연결

요청 한도·크레딧을 읽을 계정의 Warp API 토큰을 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `WARP_API_KEY`, `WARP_TOKEN`.

`coderim usage --provider warp`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/warp.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
