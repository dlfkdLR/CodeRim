# DeepSeek

[English](../../providers/deepseek.md) · **한국어**

API 크레딧 잔액.

CLI 제공업체 ID: `deepseek`.

## 연결

잔액 조회용 DeepSeek API 키를 입력합니다. 별도 플랫폼 세션이 추가 사용량 상세를 제공할 수 있습니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `DEEPSEEK_API_KEY`, `DEEPSEEK_KEY`, `DEEPSEEK_PLATFORM_TOKEN`, `DEEPSEEK_USER_TOKEN`.

`coderim usage --provider deepseek`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/deepseek.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
