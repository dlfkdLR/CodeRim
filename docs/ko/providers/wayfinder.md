# Wayfinder

[English](../../providers/wayfinder.md) · **한국어**

로컬 게이트웨이 상태와 경로 통계.

CLI 제공업체 ID: `wayfinder`.

## 연결

WAYFINDER_GATEWAY_URL에 실행 중인 로컬 게이트웨이를 지정합니다. 계정 구독 한도가 아니라 라우터 상태·통계를 모니터링합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `WAYFINDER_GATEWAY_URL`.

`coderim usage --provider wayfinder`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/wayfinder.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
