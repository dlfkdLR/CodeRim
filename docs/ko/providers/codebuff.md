# Codebuff

[English](../../providers/codebuff.md) · **한국어**

크레딧과 주간 사용 한도.

CLI 제공업체 ID: `codebuff`.

## 연결

Codebuff API 토큰을 입력하거나 CLI에 로그인해 지원되는 로컬 자격 증명 파일을 준비합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `CODEBUFF_API_KEY`, `CODEBUFF_API_URL`.

`coderim usage --provider codebuff`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/codebuff.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
