# Crof

[English](../../providers/crof.md) · **한국어**

크레딧 잔액과 사용 가능한 요청 할당량.

CLI 제공업체 ID: `crof`.

## 연결

계정 사용량 엔드포인트의 Crof API 키를 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `CROFAI_API_KEY`, `CROF_API_KEY`.

`coderim usage --provider crof`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/crof.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
