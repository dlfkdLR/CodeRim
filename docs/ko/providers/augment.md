# Augment

[English](../../providers/augment.md) · **한국어**

계정 크레딧.

CLI 제공업체 ID: `augment`.

## 연결

Augment CLI에 로그인하거나 지원되는 로그인 브라우저 세션 가져오기를 켭니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

`coderim usage --provider augment`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/augment.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
