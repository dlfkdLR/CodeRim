# Windsurf

[English](../../providers/windsurf.md) · **한국어**

에디터 또는 브라우저 세션에서 가져오는 요금제 사용량.

CLI 제공업체 ID: `windsurf`.

## 연결

Windsurf에 로그인합니다. 이용 가능한 로컬 편집기 세션·캐시를 사용하거나 브라우저 세션 가져오기를 명시적으로 켭니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

`coderim usage --provider windsurf`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/windsurf.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
