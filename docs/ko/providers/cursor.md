# Cursor

[English](../../providers/cursor.md) · **한국어**

에디터 또는 Cursor Agent에서 가져오는 요금제 사용량.

CLI 제공업체 ID: `cursor`.

## 연결

1. 이 Mac에서 Cursor 또는 Cursor Agent에 로그인합니다.
2. **Settings → Providers → Add Provider**에서 **Cursor**를 추가합니다.
3. 제공업체를 새로고침해 계정에서 제공하는 사용량 한도를 불러옵니다.

`coderim usage --provider cursor`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.
