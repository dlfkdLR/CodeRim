# Gemini

[English](../../providers/gemini-cli.md) · **한국어**

Gemini CLI 인증 정보를 통해 확인하는 할당량.

**Gemini CLI**라는 이름으로도 알려져 있습니다. 앱에는 **Gemini**로 표시됩니다.

CLI 제공업체 ID: `gemini-cli`.

## 연결

이 Mac에서 Gemini CLI에 로그인합니다. CodeRim은 기존 OAuth 자격 증명으로 한도를 조회합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `GEMINI_OAUTH2_JS_PATH`, `GEMINI_OAUTH_CLIENT_ID`, `GEMINI_OAUTH_CLIENT_SECRET`.

`coderim usage --provider gemini-cli`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/gemini.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
