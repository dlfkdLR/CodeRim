# Moonshot / Kimi Open Platform

[English](../../providers/moonshot.md) · **한국어**

Kimi Open Platform API 잔액.

**Kimi API**라는 이름으로도 알려져 있습니다. 앱에는 **Moonshot / Kimi Open Platform**로 표시됩니다.

CLI 제공업체 ID: `moonshot`.

## 연결

Moonshot/Kimi Open Platform API 키를 입력합니다. 계정 잔액 엔드포인트에 맞는 지역을 선택합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `MOONSHOT_API_KEY`, `MOONSHOT_KEY`, `MOONSHOT_REGION`.

`coderim usage --provider moonshot`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/moonshot.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
