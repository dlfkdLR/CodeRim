# Grok

[English](../../providers/grok.md) · **한국어**

Grok CLI를 통해 확인하는 크레딧과 사용량.

CLI 제공업체 ID: `grok`.

## 연결

1. 이 Mac에서 Grok CLI에 로그인합니다.
2. **Settings → Providers → Add Provider**에서 **Grok**을 추가합니다.
3. 새로고침해 제공되는 크레딧·사용량을 불러옵니다. **xAI** 플랫폼 API 제공업체와 별개입니다.

`coderim usage --provider grok`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.
