# OpenCode

[English](../../providers/opencode-zen.md) · **한국어**

Zen 워크스페이스 구독 사용량.

**OpenCode Zen**라는 이름으로도 알려져 있습니다. 앱에는 **OpenCode**로 표시됩니다.

CLI 제공업체 ID: `opencode-zen`.

## 연결

브라우저에서 OpenCode 워크스페이스에 로그인합니다. 이 제공업체의 브라우저 세션 가져오기를 켜거나 세션 쿠키를 입력합니다. Zen 항목이며 Go 플랜은 별도 제공업체입니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `CODEXBAR_OPENCODE_WORKSPACE_ID`, `OPENCODE_API_KEY`.

`coderim usage --provider opencode-zen`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/opencode.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
