# Fireworks

[English](../../providers/fireworks.md) · **한국어**

최근 30일간 계정 지출.

CLI 제공업체 ID: `fireworks`.

## 연결

Fireworks API 키를 입력하고 Additional provider settings에 FIREWORKS_ACCOUNT_SLUG를 설정합니다. 청구 조회에는 계정 slug가 필요합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `FIREWORKS_ACCOUNT_SLUG`, `FIREWORKS_API_KEY`, `FIREWORKS_KEY`.

`coderim usage --provider fireworks`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/fireworks.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
