# ClawRouter

[English](../../providers/clawrouter.md) · **한국어**

라우터 지출과 월간 예산.

CLI 제공업체 ID: `clawrouter`.

## 연결

월간 예산·사용량 엔드포인트의 라우터 API 키와 기본 URL을 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `CLAWROUTER_API_KEY`, `CLAWROUTER_BASE_URL`.

`coderim usage --provider clawrouter`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/clawrouter.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
