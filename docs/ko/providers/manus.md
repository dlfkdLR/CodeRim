# Manus

[English](../../providers/manus.md) · **한국어**

크레딧 잔액과 일일 허용 사용량.

CLI 제공업체 ID: `manus`.

## 연결

로그인된 Manus 브라우저 세션을 가져오거나 session_id 쿠키를 수동 세션으로 입력합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `MANUS_COOKIE`, `MANUS_SESSION_TOKEN`.

`coderim usage --provider manus`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/manus.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
