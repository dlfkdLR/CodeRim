# Droid

[English](../../providers/factory.md) · **한국어**

Factory 사용량 및 청구 정보.

**Factory**라는 이름으로도 알려져 있습니다. 앱에는 **Droid**로 표시됩니다.

CLI 제공업체 ID: `factory`.

## 연결

Factory API 키 또는 지원되는 로그인 Factory 브라우저 세션을 사용합니다. CodeRim 목록에는 Factory가 Droid로 표시됩니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `FACTORY_API_KEY`.

`coderim usage --provider factory`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/factory.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
