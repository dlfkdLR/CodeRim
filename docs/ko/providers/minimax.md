# MiniMax

[English](../../providers/minimax.md) · **한국어**

Coding Plan 사용량.

CLI 제공업체 ID: `minimax`.

## 연결

Coding Plan API 키 또는 로그인된 Coding Plan 브라우저 세션을 사용합니다. 수동 Cookie 헤더도 지원합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `MINIMAX_API_KEY`, `MINIMAX_CODING_API_KEY`, `MINIMAX_CODING_PLAN_URL`, `MINIMAX_COOKIE`, `MINIMAX_COOKIE_HEADER`, `MINIMAX_HOST`, `MINIMAX_REMAINS_URL`, `MINIMAX_REQUIRE_PROVIDER_ENDPOINT_OVERRIDES`.

`coderim usage --provider minimax`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/minimax.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
