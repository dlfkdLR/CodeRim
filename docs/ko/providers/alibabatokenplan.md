# Alibaba Token Plan

[English](../../providers/alibabatokenplan.md) · **한국어**

Bailian 토큰 요금제 사용량.

CLI 제공업체 ID: `alibabatokenplan`.

## 연결

로그인된 Bailian CLI 또는 Bailian 브라우저 세션을 사용합니다. 구독이 있는 토큰 플랜 계정과 지역을 선택합니다.

위 소스로 [공통 연결 단계](../providers.md#제공업체-연결)를 따릅니다.

**Additional provider settings:** `ALIBABA_TOKEN_PLAN_HOST`, `ALIBABA_TOKEN_PLAN_QUOTA_URL`.

`coderim usage --provider alibabatokenplan`로 [앱 스냅샷을 확인](../cli.md)합니다. [측정값과 문제 해결](../providers.md#측정값과-문제-해결)을 참고하세요.

[고정 소스 안내](https://github.com/steipete/CodexBar/blob/51ed16bdd3abe35ec53af99818e1b5f0d2a631d3/docs/alibaba-token-plan.md). 연결은 [CodeRim 설정](../providers.md#제공업체-연결)을 사용합니다.
