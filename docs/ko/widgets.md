# macOS 위젯

[English](../widgets.md) · **한국어**

macOS 14 이상에서 알림 센터를 열거나 데스크톱을 오른쪽 클릭해 **Edit Widgets**를 선택합니다. **CodeRim**을 검색합니다.

- **CodeRim Usage** — 세션·주간 또는 제공업체별 한도 막대, 남은 값, 초기화까지의 시간. 소형·중형·대형.
- **CodeRim History** — 일별 토큰 막대, 오늘·최근·30일 토큰 합계, 지원되는 예상 API 비용. 중형·대형.
- **CodeRim Metric** — 자동, 오늘 토큰, 오늘 예상 API 비용, 30일 예상 API 비용, 크레딧 중 값 하나. 소형.
- **CodeRim Overview** — 가능한 경우 로컬 토큰, 그 외에는 제공업체 한도·상태. 소형·중형·대형. 기존 Overview·Limits 위젯은 저장한 ID와 제공업체 선택을 유지합니다.

추가한 위젯을 오른쪽 클릭하고 **Edit Widget**에서 목록의 제공업체를 선택합니다. Metric에는 지표 선택도 있습니다. 위젯별 선택을 기억하며 클릭하면 CodeRim Usage를 엽니다. History는 현재 Codex·Claude 로컬 세션만 지원합니다. 다른 제공업체에는 실제 한도·상태를 유지하며 히스토리를 만들어 내지 않습니다.

레이아웃은 제공한 CodexBar 참고를 따라 간결한 제공업체 헤더, 기본 색상, 가로 사용량 막대, 일별 히스토리, 읽기 쉬운 합계를 사용합니다. 백분율·개수·금액은 구분합니다. 오래된 측정값은 **Last known**, 날짜가 지난 일별 비용은 **Latest**로 표시합니다. 상한을 모르면 남은 양을 100%로 만들지 않습니다. 라이트·다크 모드는 시스템 색상을 사용합니다.

갱신 일정은 WidgetKit이 제어합니다. 앱은 reload 요청 전에 스냅샷을 저장하고 일반 요청 빈도를 제한하며 계정·상태 변경은 즉시 무효화합니다. timeline 항목은 reload 사이에도 오래된 상태를 반영합니다. 앱 새로고침이 즉각적인 데스크톱 다시 그리기를 보장하지는 않습니다.

## 없거나 오래된 위젯

설치된 CodeRim을 한 번 실행하고 제공업체 연결을 확인한 뒤 최신 값을 위해 실행 상태로 둡니다. 앱이 닫혔거나 제공업체 새로고침이 실패하면 마지막 측정값을 표시하는 것이 정상입니다. WidgetKit은 앱 새로고침 뒤에도 다시 그리기를 늦출 수 있습니다.

여전히 위젯이 나타나지 않거나 갱신하지 않으면 [설치 진단](../../Documentation/CLI_WIDGETS.ko.md#if-widgets-are-absent-or-stale)을 참고합니다. 미리보기 이미지만으로 설치된 위젯의 스냅샷 접근을 확인할 수 없습니다.
