# Get started

1. [Install CodeRim](installation.md), open it, then choose **Settings → Providers → Add Provider**.
2. Select the tools you use. Open each provider's settings and complete its [connection guide](providers.md). Adding an entry does not sign you into that service.
3. Hover a ring for usage windows, reset times, account plans, and active sessions.
4. Open **Settings → Usage** for Codex and Claude Code token history. Use the notch's account control for [saved accounts](accounts.md).

## Make it yours

Use **Settings → Notch** to choose the screen edge, size, colours, used/remaining readings, and alerts. Option-drag repositions the notch. The menu-bar item opens Usage, Settings, updates, or the hidden notch.

Provider limit alerts and session-completion peeks/sounds have separate controls. Removing a provider stops its monitoring without signing out of the original tool.
