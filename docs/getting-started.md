# Get started

**English** · [한국어](ko/getting-started.md)

1. [Install CodeRim](installation.md), open it, then choose **Settings → Providers → Add Provider**.
2. Select your tools and follow their [connection guides](providers.md). Adding an entry does not sign you into that service.
3. Hover a ring for usage windows, reset times, plans, and session activity. Only selected providers are monitored.
4. Open **Settings → Usage** and choose a connected Codex or Claude Code integration. In the current macOS source, **Overview**, **Usage analytics**, and the selected provider's **Limits** share the same toolbar. Other quota-only providers do not gain local token analytics.
5. Use the notch's account control or **Switch** in Usage for [saved accounts](accounts.md).

## Make it yours

Use **Settings → Notch** for the edge, size, colors, used/remaining readings, and alerts. Option-drag repositions the macOS notch. The menu-bar or tray menu opens Usage, Settings, updates, or the hidden notch.

In the current macOS source, session token counts, task duration, and unknown-status tasks are off by default. Sub-agents appear below their parent chat; their tokens contribute to the main-chat count once. Counts come from records on this computer. Missing local records leave the count unavailable.

Limit alerts and session-completion peeks/sounds have separate controls. Removing a provider stops monitoring without signing out of the original tool. [Windows](windows.md) and [iPhone](iphone.md) have separate installation and verification requirements.
