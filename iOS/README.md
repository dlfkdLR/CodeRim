# CodeRim for iPhone

**English** · [한국어](README.ko.md)

Open `CodeRimMobile.xcodeproj` and scheme `CodeRimMobile`. Source supports iOS 17.2+ native settings, provider/device selection, and a lock-screen/Dynamic Island Live Activity. Version 1.0.0 is available to invited internal TestFlight testers; it has not been submitted for public App Store review. Automatic Live Activity starts and background updates require the relay's APNs configuration (`/health` reports `"push": true`).
