# CodeRim for Windows 2.1.36

This Windows release advances from 2.1.34 and includes the Windows changes from PR #167 and the integrated hardening in PR #129. The matching macOS release is also 2.1.36. x64 and ARM64 MSI installers are planned.

- Large Claude transcripts now use bounded title reads and a bounded title cache. Usage merging preserves partial and repaired provenance, and local account reads reject stale credential updates.
- Local history retains partial-read evidence by range, and duplicate counters preserve a valid input split. Failed refreshes keep partial-history warnings; cancelled pairing answers cannot activate a connection.
- The iPhone pairing code is scanned or pasted inside the CodeRim app. Old `coderim://pair` QR codes must be regenerated by the updated desktop client. Deploy the matching relay and iPhone app changes together.
- Native x64 and ARM64 CI now tests the packaged ZIP, MSI install and rollback, MSIX install, UI smoke checks and CLI aliases on separate runners.

## Verification and limits

CI for this release commit checks Core, release-version consistency, and native x64/ARM64 ZIP, MSI and MSIX behavior. Signed update manifests, public release assets, final installers and real provider accounts require separate release validation. The iPhone app remains a development app, not an App Store release; preparing this version does not publish it.
