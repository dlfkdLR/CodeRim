# CodeRim for Windows 2.1.36

This Windows release advances from 2.1.34 and includes the Windows changes from PR #166. The matching macOS release is also 2.1.36. x64 and ARM64 MSI installers are planned.

- Large Claude transcripts now use bounded title reads and a bounded title cache. Usage merging preserves partial and repaired provenance, and local account reads reject stale credential updates.
- The iPhone pairing code is scanned or pasted inside the CodeRim app. Old `coderim://pair` QR codes must be regenerated by the updated desktop client. Deploy the matching relay and iPhone app changes together.
- Native x64 and ARM64 CI now tests the packaged ZIP, MSI install and rollback, MSIX install, UI smoke checks and CLI aliases on separate runners.

## Verification and limits

The contributor fork's Windows workflow passed Core tests and native x64 and ARM64 package checks at PR head `f137e514`. Release-version packaging, signed update manifests, the final installers and real provider accounts still need validation on the release commit. The iPhone app remains a development app, not an App Store release.
