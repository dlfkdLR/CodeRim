# CodeRim Windows 2.1.11

Published September 27, 2026, with x64 and ARM64 MSI installers. The Mac application and release configuration are unchanged. Windows widgets remain outside scope.

## Notch and interface

- Keep the floating notch out of the Windows application switcher using tool-window shell flags, including after hiding and showing it again.
- Remove rectangular system button backgrounds and the overlapping Settings tooltip. Keep circular keyboard focus and transparent space around the controls.
- Align native window bounds with the notch at each screen edge and application size. Preserve reveal, fold and provider-ring animations.
- Bring Usage navigation, compact controls, account-limit cards, provider lists and retained selection closer to the fixed Mac reference.

## Accounts and usage

- Preserve independent detected account details when quota requests fail, without reusing another account's quota or identity.
- Update or clear Command Code's plan from a successful subscription response even when a later usage request fails.
- Discover the current Windows Cursor agent login when no usable editor login exists. Keep editor/agent identities separate, honor expiry and explicit credential selection, and accept valid current credential/config files up to 1 MiB.
- Retain local token, project and session accounting fixes and restore Claude integration settings through the disconnect command while preserving later user edits.

## Installation and updates

- Use a distinct 2.1.11 MSI identity so it can upgrade an existing 2.1.10 installation.
- Keep Windows release version validation independent of the Mac release version.
- Test the actual public 2.1.10 MSI upgrade and rollback in addition to the earlier 2.1.8 migration path. The authenticated automatic-update test selects the exact candidate version.

## Verification status

[CI73](https://github.com/dlfkdLR/CodeRim/actions/runs/36319397142) verifies exact source `1c80858808d716756577efe736912593562a011b` on Windows x64 and ARM64. Each architecture passes 2,257 Core tests, builds, release-version checks and 11 installer lifecycle groups, including the actual public 2.1.10 MSI upgrade and rollback. Installed and direct executions cover the notch, account and UI regressions. [Authenticated update handoff](https://github.com/dlfkdLR/CodeRim/actions/runs/36321235743) also passes on both architectures: the old-version QA fixture verifies the real signature, applies the exact installer and automatically relaunches 2.1.11 while preserving its separate data directory. This fixture is distinct from the actual public 2.1.10 MSI upgrade/rollback test. After publication, the production discovery/authentication/download/cache code selects 2.1.11 and verifies both public MSI files anonymously against the same SHA-256 values. This public probe verifies package delivery, not a user-PC GUI installation.

Fixtures do not establish real provider authentication, physical Alt+Tab operation, mixed-DPI monitors or complete pixel parity. ARM64 desktop captures still show the underlying desktop rather than the notch, and pointer/wheel evidence remains inconclusive.
