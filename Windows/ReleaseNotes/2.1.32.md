# CodeRim for Windows 2.1.32

A Windows-only release; macOS is at 2.1.31. The Windows version jumps from 2.1.20 because the numbers 2.1.21 to 2.1.31 were used by macOS releases. x64 and ARM64 MSI installers.

- **View limits for another saved Codex account.** On Settings → Accounts, a saved Codex account that is not the current one has a **View limits** button. It reads that account's limits in a private, temporary Codex home, so the CLI stays signed in to the current account. The temporary folder is removed afterwards, the official logout is never run, and a login the read renews is saved back (also when the read fails) so the saved account keeps working.
- **A stale reading says how old it is.** When a provider's last reading has gone old and refreshing failed, the notch card shows "Last read 12 min ago · refresh failed" instead of "Waiting for the first reading…". A provider that was never read keeps the waiting line.

Existing 2.1.x installations update themselves from **Information → Check for updates**.

## Verification

The Windows CI passed the Core tests, the native smoke checks and the x64 and ARM64 MSI lifecycle on the pull requests that added these changes. **View limits** has not been used against a second real Codex account, only compiled and exercised by CI; the stale-reading line was checked by tests, not on screen.
