# CodeRim for Windows 2.1.19

Fixes **Information → Check for updates**. x64 and ARM64 MSI installers; macOS is unchanged at 2.1.15.

- Updates finish on slower connections. The whole installer download had to complete within five minutes, so it failed every time below roughly 470 KB/s. The limit now follows the installer's size (up to two hours), and a stalled connection is still stopped after a minute without data.
- The download shows its progress as a percentage instead of a long "Checking…", including when the automatic background check had already started it.
- A failed update says why: no connection, GitHub limiting checks from this network, a stalled download, a download that failed verification, or no room to save it.

Existing 2.1.x installations update themselves; if 2.1.18 or earlier could not finish an update, download this installer once from the release page.
