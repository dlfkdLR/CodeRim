# CodeRim 2.1.41 for Windows

- Observe stdout, stderr, stdin and process exit together for provider commands and account RPC. Output-limit failures can stop a child even when it never reads its input.
- Propagate cancellation to RPC writes and observe outstanding IO during cleanup, preventing a blocked write from outliving the caller unnoticed.
- Preserve the existing settings, saved-account encryption, usage database and authenticated installer-update trust.

Publication requires separate x64 and ARM64 MSI validation. The installer update manifests use the existing Ed25519 key; this does not claim Authenticode publisher signing.

## 한국어

- 제공업체 명령과 계정 RPC의 stdout·stderr·stdin·프로세스 종료를 함께 관찰합니다. 자식 프로세스가 입력을 읽지 않아도 출력 제한 오류가 발생하면 정리합니다.
- RPC 쓰기에 취소를 전달하고 정리 중인 IO의 실패도 관찰해, 막힌 쓰기가 호출 종료 뒤에 남지 않도록 합니다.
- 기존 설정·저장 계정 암호화·사용량 DB·인증된 설치 파일 업데이트의 신뢰를 유지합니다.

게시 전 x64·ARM64 MSI를 각각 검증해야 합니다. 설치 파일 업데이트 manifest는 기존 Ed25519 키를 사용하며, Authenticode 게시자 서명을 뜻하지는 않습니다.
