# CodeRim for Windows 2.1.18

A fix for the notch's first opening. x64 and ARM64 MSI installers; macOS is unchanged at 2.1.15.

- Opening the notch no longer flickers. The window used to move and resize before its new contents were drawn, so for a moment the closed pill (or, when folding, the open card) showed at the wrong place. The move now happens with the frame that draws the new contents.
- The first opening after CodeRim starts is smooth: the open notch is drawn once off screen while the app is idle, so the first real opening no longer stalls on first-use work.

Existing 2.1.x installations update themselves.
