# CodeRim for Windows 2.1.20

Accuracy and connection fixes from a full audit, released together with macOS 2.1.20. x64 and ARM64 MSI installers.

- Usage logs whose counters grow inconsistently are counted for the part that is certain and marked partial, instead of being dropped while the period still said exact. The correction is stored with the history, so it stays marked after the logs are gone.
- History that did not change is no longer saved and read again on every refresh; a refresh dropped by an account switch is read again next time.
- Old partial readings show as stale, like complete ones.
- 80%/100% alerts are kept per account and start over in a new limit period.
- iPhone sharing: an answer that never finishes can no longer leave pairing, sharing or disconnect waiting forever.
- The usage database now carries a schema version; one written by a newer CodeRim is read but never changed.

Existing 2.1.x installations update themselves from **Information → Check for updates**.
