# CodeRim for Windows 2.1.34

A Windows-only release; macOS is at 2.1.33. 2.1.33 was a macOS release, so Windows goes from 2.1.32 to 2.1.34. x64 and ARM64 MSI installers.

- **Sound for sub-agents.** Settings → Edge Notch → When a Session Ends has a new **Sound for sub-agents** switch, off by default. A sub-agent finishing no longer plays the chime; the chat that started it still does, even when both finish together.

Existing 2.1.x installations update themselves from **Information → Check for updates**.

## Verification

The Windows CI runs the Core tests, the native smoke checks and the x64 and ARM64 MSI lifecycle on the pull request. The new switch was compiled and exercised by CI only; it was not checked on a real Windows screen, and the Windows notch wake area is unchanged.
