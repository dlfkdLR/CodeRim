# 개인정보와 저장 경계

[English](PRIVACY.md) · **한국어**

## 로컬 데이터

Codex와 Claude Code 히스토리는 알려진 세션 로그 위치에서 이 컴퓨터 안에서 처리하며, 별도의 로컬 데이터베이스를 사용합니다. 로컬 분석을 위해 집계 수치, 시각, 정규화된 모델 ID, 키를 사용한 프로젝트 식별자, 해시된 세션 관계, 프로젝트 폴더의 마지막 이름, Codex 이미지 개수, 파서 체크포인트를 저장합니다.

사용량 테이블에 프롬프트, 응답, 추론, 소스 코드, 도구 내용, 이미지 바이트, 원본 세션 경로, 전체 프로젝트 경로를 저장하지 않습니다. 로컬 집계는 브라우저 세션이나 계정 자격 증명을 사용하지 않습니다. CLI와 데스크톱 위젯은 계정 이메일, 자격 증명, 대화 제목, 원본 경로가 없는 집계 스냅샷을 읽습니다.

## 자격 증명과 요청

모니터링은 원래 도구의 로그인이나 CodeRim에서 설정한 연결을 사용할 수 있습니다. macOS 추가 제공업체 설정은 별도의 CodeRim Keychain 항목에 저장합니다. 지원하는 제공업체별로 브라우저 세션 가져오기를 켭니다. 모든 브라우저 프로필을 읽도록 일괄 허용하는 설정이 아닙니다. Windows는 별도의 보호된 로컬 저장소를 사용합니다.

Codex 계정 한도는 검증한 로컬 Codex app-server를 사용하고, Claude 한도는 로컬 상태 줄 도우미를 사용합니다. 다른 제공업체 요청은 해당 서비스나 설정한 엔드포인트로 갑니다. 계정 저장·전환은 명시적 동작이며 한도에 따른 자동 전환은 없습니다. 사용량 테이블과 진단 정보에 자격 증명을 넣지 않습니다.

CodeRim 2.1.13은 새 기본 설정 등록 시 별도 ChatGPT 프로필 히스토리를 켜고 기존 저장 값을 존중합니다. 현재 Codex의 액세스 토큰과 계정 ID만 읽어 고정 `https://chatgpt.com/backend-api/wham/profiles/me` 엔드포인트로 보내며 리다이렉트를 거부합니다. 자격 증명과 응답은 메모리에만 유지합니다. 계정 합계는 로컬 히스토리 테이블에 저장하지 않습니다. [범위와 갱신 시점](USAGE.ko.md)을 참고합니다.

Sparkle은 GitHub 업데이트 인프라를 조회하고 Windows Setup 업데이트는 고정된 릴리스 키와 체크섬을 사용합니다. 요청에는 IP 주소 같은 일반 연결 정보가 드러나며 프롬프트, 토큰 히스토리, 제공업체 자격 증명을 첨부하지 않습니다. 자동 업데이트 확인은 **Settings → General**에서 설정합니다.

## 선택적 iPhone 공유

iPhone 앱과 relay는 별도의 개발 기능으로 서버 설정과 연결을 명시적으로 해야 합니다. 데스크톱은 허용 목록에 있는 제공업체명, 남은 백분율, 측정 시각, 로컬 Today 토큰, 작업 상태·개수만 전송합니다. 작업 제목 공유는 기본적으로 꺼져 있으며 **Share task titles**를 켜면 제목도 전송합니다. 서비스 자격 증명, 세션 ID, 전체 경로, 프롬프트, 대화 원문은 공유하지 않습니다.

relay는 마지막 스냅샷, 기기·선택 메타데이터, Apple subject ID, 해시된 Bearer 토큰, 전달에 필요한 APNs 활동 토큰을 저장합니다. HTTPS는 전송을 보호하지만 relay는 공유한 사용량을 읽을 수 있습니다. 종단 간 암호화 전송은 아닙니다. [iPhone 설정](IPHONE.ko.md)과 [relay 참고 문서](IPHONE.ko.md)를 확인합니다.

## 제어

- 모니터링할 제공업체만 선택합니다. 제거하면 모니터링을 중지하며 원래 도구에서는 로그아웃하지 않습니다.
- AWS Bedrock, Azure OpenAI, 일부 Doubao 소스는 과금될 수 있는 조회 전에 **Allow potentially billed monitoring requests**를 켜야 합니다.
- **Settings → Providers → Codex 또는 Claude Code**에서 해당 서비스의 집계 데이터를 재구축·삭제합니다. 원본 세션 로그는 유지하며 삭제 시 가져오기 기준 시각을 기록합니다.
- 디버그 로그는 기본적으로 꺼져 있으며 자격 증명과 대화 내용은 제외합니다. 버그 보고에 개인 대화 기록을 첨부하지 마세요.

## 저장 지도

| 데이터 | 저장 위치·경계 |
| --- | --- |
| 정규 로컬 토큰 이벤트·체크포인트 | 별도 소유자 전용 SQLite; 원문·전체 경로 제외 |
| 정규화한 마지막 한도·측정 시각 | UserDefaults `notchLastGoodReadings`의 `UsageArchive`; 일별 로컬 합계 제외 |
| CLI·위젯 집계 데이터 | 원자적 소유자 전용 `snapshot.json`; local-file 또는 승인 App Group 전송 |
| app-server 원본 응답 | 메모리 저장소; 내보내기에서 자격 증명 제외 |
| ChatGPT 프로필 자격 증명·응답 | 고정 엔드포인트 메모리 요청; SQLite·UserDefaults·Keychain·진단에 저장하지 않음 |
| 저장한 구독·추가 제공업체 자격 증명 | 전용 비동기화 macOS Keychain; Windows DPAPI CurrentUser |
| 선택적 모바일 데이터 | HTTPS relay의 기기별 마지막 스냅샷; 제목은 명시적 공유 시에만 |

Application Support는 `0700`, SQLite·잠금·fingerprint·스냅샷 파일은 `0600`입니다. 탐색·열기는 포함 범위, 소유자, 링크, 입력 상한을 검사합니다. 삭제는 로컬 집계에 SQLite secure deletion·WAL 절단·vacuum을 사용하며 삭제 기준·Claude 해시 제외 목록은 유지합니다. 디버그 로그는 기본 off이고 원본 오류·내용 대신 고정 운영 이벤트·개수를 쓰며 1 MiB에서 회전합니다. 로컬 집계는 네트워크 의존성과 텔레메트리가 없습니다. 명시적 제공업체·프로필·업데이트·relay 요청은 각각 문서화한 경계를 사용합니다.
