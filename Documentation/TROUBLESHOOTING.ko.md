# 기술 문제 해결

[English](TROUBLESHOOTING.md) · **한국어**

제공업체 연결, 히스토리 누락, CLI·위젯, 앱 이름 변경, Homebrew·macOS 복구는 [사용자 문제 해결 안내](../docs/ko/troubleshooting.md)를 따릅니다. Windows 설치·업데이트 복구는 [별도 안내](WINDOWS.ko.md)를 사용합니다.

## 데이터베이스·설치 진단

스키마 검사에서 거부하면 파괴적 삭제 전에 파일을 보존합니다. 스키마 17에는 트랜잭션 호환·복구가 있습니다. 이전 빌드가 열지 못해도 정상 이벤트가 남아 있을 수 있습니다. 재구축은 집계 복구 단계이며 거부된 파일이 비어 있었다는 증거가 아닙니다. 선택 서비스의 기준 시각과 1 GiB·원본 50,000개 안전 제한을 유지합니다.

새 번들은 디스크에 있고 이전 프로세스가 실행 중이면 Sparkle의 “An error occurred while launching the installer”가 나타날 수 있습니다. 설치·실행 버전을 확인합니다. updater는 대기 중인 설치에 **Restart Now**를 제시할 수 있습니다. 설정·히스토리를 보존하며 다운로드 완료만으로 설치 성공을 판단하지 않습니다.

정확한 버전·build, 선택 제공업체, 상태, 재현, 제한된 진단 로그를 보고하며 자격 증명·대화 기록은 제외합니다. 소스·로컬 테스트, 패키지, 설치 동작, 원격 CI를 구분합니다. [개인정보 경계](PRIVACY.ko.md)와 [릴리스 검증](RELEASING.ko.md)을 따릅니다.
