# CodeRim 2.1.41

## macOS

- Recheck Claude sub-agent activity when a completed or long-quiet file changes, and keep each parent session's cache separate. Atomic file replacements no longer leave resumed work hidden behind an old completed result.
- Bound Claude registry and transcript reads, validate session metadata, and release caches after sessions disappear. Activity logs omit conversation names and full project paths.
- Mark Companion readings stale when their known timestamp or reset has expired, while preserving older partial readings without timestamps.
- Reject unsupported fingerprint-key file types without blocking app startup. Existing valid keys, settings and usage history keep their identities.

## Windows

- Provider and account-RPC processes observe input, output failures and cancellation together, so blocked input does not hold up output-error cleanup. See the [Windows notes](../../Windows/ReleaseNotes/2.1.41.md).

## Relay source

Pending QR pairing grants use authenticated encryption. Ended activities clear retained display content, including retry and late-response paths. These server changes require deployment of the matching relay source; desktop communication remains compatible with the existing protocol.

## 한국어

- 완료됐거나 오래 조용했던 Claude 하위 에이전트 파일이 바뀌면 활동을 다시 확인하고 부모 세션별 캐시를 분리합니다. 파일이 원자적으로 교체돼도 재개된 작업이 이전 완료 상태에 가려지지 않도록 수정했습니다.
- Claude 레지스트리·대화 파일의 읽기 크기와 세션 정보를 검증하고, 사라진 세션의 캐시를 정리합니다. 활동 로그에서 대화 이름과 전체 프로젝트 경로를 제외합니다.
- 측정 시각이나 리셋 시각이 만료된 Companion 사용량은 오래된 값으로 표시합니다. 시각이 없는 이전 partial 데이터와의 호환성은 유지합니다.
- 지원하지 않는 fingerprint key 파일 형식 때문에 앱 시작이 멈추지 않도록 합니다. 정상적인 기존 키·설정·사용량 기록의 식별자는 유지합니다.
- Windows는 제공업체·계정 RPC의 입력·출력 오류·취소를 함께 관찰해 막힌 입력이 오류 정리를 지연하지 않게 합니다.
- 릴레이 소스는 대기 중인 QR 페어링 grant를 인증 암호화하고, 종료된 활동의 표시 내용이 재시도·늦은 응답으로 남거나 복원되지 않게 합니다. 서버 변경은 해당 릴레이 배포가 필요하며 데스크톱 통신 규약의 호환성을 유지합니다.
