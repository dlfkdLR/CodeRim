# CodeRim 2.1.7

This release fixes usage-history regressions on both platforms and brings the Windows Settings layout and interactions closer to the macOS app. Windows Widgets remain excluded.

## macOS

- Reject late Cursor quota results after the signed-in account changes.
- Count a sub-agent's first new image even when it arrives before its first token event. Existing affected session checkpoints are replayed automatically; token records, clear-history cutoffs and absent-source metadata are preserved.

## Windows

- Use the six macOS Settings categories, grouped provider and Information pages, system light/dark/high-contrast colors and matching Usage navigation. Preserve keyboard focus, selected providers and the last visible notch mode.
- Stop background refresh in Manual mode. Clear provider cards when moving to notch controls, keep explicit account menus open until dismissed, and show finished/blocked attention independently of sound.
- Add account/additional/reset-credit visibility controls, session image counts, direct sub-agent links, Diagnostics CLI installation, private bounded debug logs and separate finished/blocked sound choices.
- Keep parsed totals when logs append during collection, while rejecting rewritten/replaced prefixes. Deduplicate image observations across copied or reformatted archives. History clearing prevents old tokens and images from reappearing.
- Keep session filters, sidebar selection and sub-agent links consistent with the selected period.
- Open validated Codex conversation links or the live Claude session application from activity rows and completion peeks; reject reused process IDs and fall back to local sessions when no application is available.

## Verification and limits

Local macOS tests executed 922 cases, with 9 environment-dependent skips and zero failures. Windows core tests execute 285 cases on Windows. Native Windows x64 CI exercises synthetic WPF views, minimum-size themes, notch edges/scales, metadata/navigation controls, protected credential storage, CLI behavior and per-user installation. Both x64 and ARM64 packages are built.

Live authentication across every provider, Windows ARM64 execution and physical mixed-DPI desktop input are separate from these checks. Hosted-runner hover checks identify routed synthetic events explicitly. macOS and Windows continue to use different OS authentication and update mechanisms; see the [Windows capability guide](https://github.com/dlfkdLR/CodeRim/blob/main/Documentation/WINDOWS.md). No claim of identical pixels on every display or complete live-account verification is made.

## Installation

macOS 14 or later; Universal 2 for Apple silicon and Intel. The app is ad-hoc signed and not Apple-notarized. Windows 11 packages are self-contained and unsigned. Verify downloads using the matching SHA-256 manifest. Close the app before installing the new package; existing settings, accounts and local data stay in their current directories.

Use the [macOS first-launch guide](https://github.com/dlfkdLR/CodeRim/blob/main/docs/installation.md) or [Windows setup guide](https://github.com/dlfkdLR/CodeRim/blob/main/Documentation/WINDOWS.md). Published release tags and artifacts are immutable.
