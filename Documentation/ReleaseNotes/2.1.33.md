# CodeRim 2.1.33

A macOS release. Windows is at 2.1.34.

## A working chat no longer shows "Done"

- Claude Code writes each streamed block of a reply as its own record, and a thinking block is saved with an end-of-turn marker before the answer follows. CodeRim read that as the end of the turn, so a chat that was still working could show "Done", and after 90 seconds drop out of the notch's list. A reply now counts as finished only when its last block is the answer, and a block still being written counts as working.

## Sub-agent sound is off by default

- Settings → Edge Notch → When a Session Ends has a new **Sound for sub-agents** switch. It is off, so a sub-agent finishing no longer plays the chime; the chat that started it still does, even when both finish together. Turn it on to hear every one. It follows the **Play a sound** switch.

## The folded notch wakes in a smaller area

- The pointer used to wake the folded notch up to about 34 pt away from the screen edge, which reached well below the menu bar beside a display notch. The band is now about 12 pt past the folded shape.

## Verification

macOS: build with warnings as errors; the full test suite passes with 0 failures, including new tests for the sub-agent sound choice, the setting's default, the thinking-block case and the narrower wake area. None of it was checked by eye on a real session.
