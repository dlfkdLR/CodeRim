# CodeRim 2.1.39 for macOS

- Open **Settings → Usage → Overview → Sessions** to browse token usage across all retained chats, including archived Codex chats. Search by title, date, or session ID, then open a chat to see its token breakdown.
- If a Codex chat's session log is missing, its local index can still supply the total. CodeRim shows these totals separately from the usage charts under **Usage analytics → All time**.

## 한국어

- **Settings → Usage → Overview → Sessions**에서 이전 Codex 채팅과 보관된 채팅의 토큰 사용량을 볼 수 있습니다. 제목, 날짜, 세션 ID로 검색하고 채팅을 열면 상세 사용량이 표시됩니다.
- 세션 로그가 없고 Codex 로컬 색인에 총 토큰 수가 남아 있으면 그 값을 표시합니다. 색인 총량은 **Usage analytics → All time** 차트와 별도로 표시합니다.
