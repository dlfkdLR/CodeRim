# CodeRim 2.1.36

This macOS release includes the desktop changes from PR #167 and the integrated hardening in PR #129. The matching Windows release is also 2.1.36, advancing from 2.1.34.

## Usage and accounts

- Large Codex and Claude transcripts are read in bounded chunks, and session title caches are bounded. Usage collection checks that the bytes it committed still match the source and keeps partial or repaired data marked as such.
- Uncounted accounting rows keep their own periods partial after source deletion; schema 18 preserves those records across log replacement. Borrowed credentials that have expired can fall back to CodeRim’s own sign-in without mixing account ownership.
- A background Codex account renewal saves its rotated login only when the saved login has not been replaced or removed. Local Antigravity access binds the loopback connection to the selected current-user process before sending its CSRF token.
- Session and credential details are no longer written to the public session log. Extended ACL checks also cover Codex profile reads and temporary login homes; inspection failures stop credential operations.
- Signed update-feed authentication no longer expires after repeated failures. Startup and release verification require the same signature policy.

## iPhone connection

- Pairing uses a code scanned or pasted inside the CodeRim iPhone app. A previously generated `coderim://pair` QR code cannot be used with the updated app; create a new code on the updated desktop client.
- Relay usage reservations, row-read accounting and hourly registration limits survive restarts. Failed starts retry through alarms, and cancelled pairing answers are revoked.
- The matching relay and iPhone app changes preserve Stop across late Live Activity registrations and retries, and an explicit Start resumes updates. Desktop, relay and iPhone versions should be updated together. The iPhone app remains a development app, not an App Store release.

## Verification and limits

The base desktop changes were verified in the upstream repository before release preparation. CI for this release commit checks Swift, iOS simulator, relay, and Universal 2 builds. Real provider accounts, physical iPhone scanning, production APNs, release signing and installed-app behavior remain separate release checks. Preparing this version does not publish a tag or release.
