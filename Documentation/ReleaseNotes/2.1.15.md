# CodeRim 2.1.15

CodeRim 2.1.15 connects providers the moment they are added, replaces the iPhone sign-in with a QR code, and fixes the stray Settings window and several notch problems on macOS and Windows.

## Providers

- Adding a provider now connects it in the same step. CodeRim reads any sign-in already on the computer; otherwise it starts the provider's own sign-in and watches for up to ten minutes until the account appears. Tools with a login command (Codex, GitHub Copilot, Cursor, Grok, OpenCode, Gemini CLI, Vertex AI) run it in a terminal window, services with a website session open their sign-in page, Gemini opens the Antigravity app, and services that need a key open their settings. The same flow runs on macOS and Windows.
- **Add Account** for Claude runs the official `claude auth login` browser sign-in when nothing is signed in yet. After switching Claude accounts, CodeRim says when Claude Desktop (which keeps its own sign-in) is still on another account.

## Notch

- macOS: the SwiftUI-owned "CodeRim Settings" window no longer reopens on its own beside the real Settings window; it also kept redrawing a hidden chart and was most of the idle CPU. Turning the notch off now stops its cursor polling instead of stacking another set each time it is turned back on.
- Claude Code sessions are named by their conversation title, and clicking one brings its own terminal tab forward (Terminal and iTerm2 by tty, Ghostty 1.3 or later by folder and title).
- Windows: the provider card glides between providers like macOS, the settings control no longer shows a click-triggered focus ring, cost estimates return for settings saved by the 09-19 to 09-23 builds, and several launch and install robustness fixes land.

## iPhone companion (development source)

- Connect by scanning the QR code a computer shows; no Apple sign-in is needed. The relay moves to a Cloudflare Worker on the free plan that rations its own use, pausing new connections and notifying connected people near the daily allowance. Without a push key it still serves usage while the app is open; background Island updates need Apple's push capability.

## Install

- macOS 14 or later: universal Apple silicon and Intel DMG/ZIP, ad-hoc signed and Sparkle-signed, without Apple notarization.
- Windows 11: separate x64 and ARM64 MSI installers. The installers are not Authenticode-signed; update manifests and payload hashes use CodeRim's pinned release key.

Checksums, signatures, and the exact validation boundary are published with the release assets.
