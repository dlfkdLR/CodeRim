# CodeRim 2.1.38 for macOS

This patch changes the computer label used by the CodeRim iPhone companion. New connections use the Mac's system Computer Name, and existing connections saved with the old default “Mac” update their label without pairing again. A custom name remains unchanged. Settings displays the active device name.

The paired Mac sends its name to the relay using its desktop token. The relay allows a computer to rename only its own record and updates the phone's current view. The relay also lets provider and device navigation finish while an APNs update is in flight. Deploy the matching relay before installing this Mac version. The iPhone app's separate TestFlight build 1.0.0(4) reuses relay connections for Dynamic Island provider and device switching; it is not included in the macOS download.

The macOS ZIP and DMG are to be Developer ID signed, notarized and stapled. The release process verifies the Universal 2 application, nested signatures, Hardened Runtime, Gatekeeper, Sparkle signature and archive checksums before publication. CI, GitHub assets, public update feed, Homebrew and installed-app behavior are checked separately.
