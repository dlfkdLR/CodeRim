# CodeRim 2.1.25

A macOS-only release with one change to the chat details card. Windows stays at 2.1.20.

## Chat details card

- A chat that has finished and is idle keeps the ring. It is drawn full in blue with a check and "Done" in the middle, and the title reads "Done" with a blue check, so the end of a turn reads as completion instead of the ring disappearing. The state figure is dropped from that card because the ring already says it.

## Verification

macOS: full local test suite with 0 failures. The card was checked by hand in the running app on the development Mac.
