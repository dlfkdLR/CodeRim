# CodeRim 2.1.31

A macOS-only release. Windows stays at 2.1.20.

## The viewed account is a plain line

- The account chooser on Settings → Usage → Codex Limits was a boxed "Account" menu. It is now the person glyph and the address, matching the header above it. Pressing it still opens your saved accounts, and choosing one only changes which limits are shown; the signed-in Codex account stays as it is. A long address is shortened in the middle instead of pushing the Switch button out of the window.

## Verification

macOS: build with warnings as errors; all 3189 tests pass with 0 failures, including the account-switcher layout tests with a very long address. The new look was not checked on screen.
