# CodeRim 2.1.28

A macOS-only release. Windows stays at 2.1.20.

## Activity on the Usage screen

- **Usage by type:** how the period's tokens split between chats, the sub-agents they started, and whatever the session list does not account for.
- **Messages:** the messages you sent per day, split by the model that answered.
- **Tool calls and skills:** per day, with an MCP server counted as one tool; skills are counted from `Skill` calls (Claude) and `SKILL.md` reads (Codex).
- **Session traits:** a session shows the share of its turns by reasoning effort and by Fast or Standard speed.
- Codex and Claude are both covered. The cards follow the range you pick, and each legend wraps in a narrow window.

## Privacy and cost

Everything is counted from the agents' own log files on this Mac and never sent anywhere. A log is read once and again only when its size or date changes, so reopening Usage does not re-read every transcript.

## Verification

macOS: full local test suite with warnings as errors; parser tests for both agents against synthetic logs; the cards were rendered offscreen at narrow and wide widths in light and dark. Real-window use over days of logs has not been exercised.
