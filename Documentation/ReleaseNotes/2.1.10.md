# CodeRim 2.1.10

This Windows release restores the motion and interaction feedback that was missing from the macOS-inspired interface.

- Fold and unfold the notch on all four edges with spring geometry and staggered provider cells. Rapidly reversing hover continues from the current position.
- Reveal Settings and account controls in sequence, and move/fade provider tooltips between readings.
- Animate usage readings and reset to an empty track; give refresh a finite full turn. Working sessions use an inner rotating arc, while waiting sessions use a yellow pulsing ring.
- Animate Settings toggles, hover fills and exact Usage token totals. Repeated refresh notifications preserve a numeric transition. Settings previews update immediately, and navigation returns the shared viewport to the top.
- Honor both the app Reduce motion preference and Windows animation policy. Hide/unload releases continuous ring animations.

## Installation and updates

Use the matching Windows 11 x64 or ARM64 MSI. The .NET runtime is included. Existing MSI installations use the authenticated automatic-update channel and restart to apply the release; old unsigned ZIP installations need the MSI once. Settings, saved accounts and local history remain outside the application directory. The installer is not Authenticode signed; its automatic-update manifest is authenticated by the existing Ed25519 key.

## Validation scope

The native workflow checks intermediate animation frames, reversal, repeated reading notifications, delayed controls, hidden-window cleanup and reduced-motion changes, alongside the existing UI, CLI, installer upgrade/rollback and data-preservation regressions. Exact execution results and limitations are recorded in the [motion audit](../WINDOWS_MOTION_2026-09-23.md). Synthetic Windows desktop evidence does not establish physical mixed-monitor parity or live authentication for every provider. Windows widgets remain excluded.

This is a Windows distribution update. macOS downloads, Sparkle and Homebrew remain on [2.1.8](https://github.com/dlfkdLR/CodeRim/releases/tag/v2.1.8).
