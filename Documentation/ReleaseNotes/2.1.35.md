# CodeRim 2.1.35

A macOS release. Windows stays at 2.1.34; it never had this card.

## The time-left card is removed

- The "Time left (beta)" card that appeared when hovering a working chat in the notch is gone, along with its Settings → Edge Notch section and the notch panel's reserved width for it.
- The optional Claude Code compaction hook switch was part of that section and is gone with it. A hook you installed earlier is left as it is; CodeRim no longer reads or manages it from Settings.
- Nothing else about sessions, the "Done" state or sounds changes.

## Verification

macOS: build with warnings as errors; the full test suite passes with 0 failures. The removal was not checked by eye on a real session.
