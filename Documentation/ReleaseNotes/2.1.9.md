# CodeRim 2.1.9

This release provides Windows 11 x64 and ARM64 MSI installers with authenticated automatic updates. Existing unsigned ZIP users can quit CodeRim and run the matching MSI once. Accounts, settings and local history remain in their separate data directory.

## Installation and updates

- Install for the current user, with Start menu and uninstall entries and the `coderim` CLI on the user PATH. The .NET runtime is included.
- Automatically check and download updates when the existing update preference is enabled. Use Information → Check for updates to check immediately and restart to install.
- Verify a bounded Ed25519-signed manifest, exact version/architecture/file/length and SHA-256 before executing an installer. The application pins its installed update worker and the worker verifies the cached MSI again.
- Wait for the original app to exit, run a Windows Installer major upgrade, and verify the installed product before relaunch. Failed upgrades use MSI rollback for application files, registration, PATH and shortcuts. Cancellation, another installer running, reboot requirements and unverified recovery states have distinct handling.
- Keep legacy Authenticode-managed ZIP installations on their existing certificate-based update channel. The public MSI refuses to overwrite that managed installation.

The first MSI does not have an Authenticode publisher certificate, so Windows may show a SmartScreen warning. The Ed25519 release signature authenticates automatic updates; it is separate from Windows publisher certification.

## Validation scope

The installer workflow exercises both native x64 and ARM64 installation, forced failure after the install script executes, restoration of prior binary hashes and registration, successful upgrades, downgrade refusal, installed app rendering, and uninstall with user-data preservation. A separate disposable old-version fixture checks the signed production MSI's worker handoff and automatic relaunch. Test-only entry points are excluded from production publishing.

These installer checks do not certify all live provider accounts or physical multi-monitor UI parity. Consult the matching release workflow results for execution evidence. Windows widgets remain outside scope.

This is a Windows distribution update. The current macOS distribution remains [2.1.8](https://github.com/dlfkdLR/CodeRim/releases/tag/v2.1.8); its Sparkle feed and Homebrew update path are unchanged.
