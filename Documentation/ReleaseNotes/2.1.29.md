# CodeRim 2.1.29

A macOS-only release. Windows stays at 2.1.20.

## Notch cards

- The speech-bubble pointer on the usage card is shorter and blunter (48 by 64 instead of 75 by 87), and the time-left card's pointer is cut the same way, so the two read as one family.
- A finished chat's card has "Chat" in its header instead of repeating "Done" next to the ring.
- The settings arc that rests under the notch is drawn at lower strength so it reads as a hint rather than a stray piece.

## Another account's limits in Settings

- Settings opens without reading your saved logins, so the account menu added in 2.1.27 never appeared there. The Codex Limits tab now has "View another account's limits": pressing it reads the saved accounts (which can ask for Keychain access) and shows the menu. Choosing an account only changes which limits are shown; the signed-in Codex account and the Codex app stay as they are. With one saved account it says there is no other.

## Verification

macOS: build with warnings as errors; notch, account and Usage tests with 0 failures. The tail shapes and the new link were checked by reading the code and tests, not on screen, and a second real account's limits have still not been read against a live account.
