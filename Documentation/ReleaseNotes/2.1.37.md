# CodeRim 2.1.37 for macOS

This patch prepares CodeRim's first Developer ID signed and Apple-notarized macOS download. Publish it only after the artifacts pass the signing, notarization and distribution checks. It advances the Mac app from 2.1.36. Windows installers and the iPhone development app have separate release processes and are not part of this Mac download.

## Account and usage reliability

- If a Codex login file is briefly unreadable, CodeRim retains the last confirmed account and tries again on the next poll. A missing file modification time also triggers a fresh read.
- Opening account settings no longer hides an error from a failed Codex CLI confirmation, and unchanged account values are not republished.
- Usage calculations and source import have clearer module boundaries. Claude sessions imported from agent transcripts keep their project attribution. The existing provider, platform and storage policies remain in place.

## macOS distribution

- The release process must sign the Universal 2 app with Developer ID and the Hardened Runtime, notarize and staple it, and confirm Gatekeeper acceptance before packaging.
- The automatic-update ZIP must use the existing Sparkle Ed25519 key. The app keeps its existing bundle identifier and update feed for the CodeRim and CodexMeter update path.
- The release must provide DMG, ZIP and SHA-256 files. The DMG is the direct-install format; Homebrew and Sparkle use the ZIP.

## Verification scope

The release gate checks the source tag, clean worktree, Universal 2 binaries, bundle metadata, nested signatures, notarization, Gatekeeper acceptance, ZIP/DMG contents and checksums, and the Sparkle update signature. GitHub assets, the public update feed, Homebrew and installed-app behavior are verified separately after publication.

This release does not claim a Windows certificate, an App Store submission, or production iPhone/APNs deployment.
