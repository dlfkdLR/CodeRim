# CodeRim 2.1.22

A macOS-only release: it turns the beta time-left card into a chat details card, lets the Claude account be switched while Claude Code is running, and fixes a memory spike at launch. Windows stays at 2.1.20.

## Chat details card

- Hovering any chat row in the notch opens the card beside the usage card, not only a working one. It shows the beta estimate and gauge when there is one, then small icon tiles: the range and finish time, state, elapsed time, tokens, the model, its reasoning effort, and Fast mode and Daybreak (Codex) as pills.
- Elapsed time and token usage moved from the row into the card. Their two Notch settings are removed and the card always shows them.
- Working Claude sub-agents are listed under the chat that started them. Codex model, effort and Daybreak come from its thread store; the Claude model and fast tier from its transcript. Fast mode for Codex is a global setting, so every Codex chat shows the same answer.
- Short turns are predicted from the chat's recent pace: turns from the last two hours count three times, the typical range is narrower, and equal ends read as one value ("4 min").
- The card glides between rows, the gauge eases in, and a small tail points at the hovered row.

## Claude accounts

- Switching the Claude account no longer requires every Claude Code session to be stopped. Running sessions use the new login from their next request; CodeRim watches the shared login for about six seconds and puts the chosen account back if a session writes the old one. A session that refreshes later can still overwrite it: restart one that shows the old account.

## Performance

- Launch no longer allocates about 500 MB. Reading past turn lengths copied what was left of a 1 MB buffer for every line; it now trims once per chunk and matches lines as bytes. Footprint after launch fell from about 517 MB to about 115 MB.
- The search for Antigravity's sign-in client read the installed app's files on the main thread every minute. It now runs in the background and repeats at most every ten minutes.
- Session token totals are summed only while the panel is open, and finished sub-agents are no longer re-read.

## Verification

macOS: 3,155 tests locally with 0 failures. The card, tiles and speeds were checked by hand in the running app on the development Mac; a live check that a running Claude CLI picks up a switched account is still outstanding.
