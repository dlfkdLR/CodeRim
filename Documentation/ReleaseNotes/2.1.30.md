# CodeRim 2.1.30

A macOS-only release. Windows stays at 2.1.20.

## A stale reading says how old it is

- A reading that had gone old showed the same "Waiting for the first reading…" as one that had never arrived. It now reads "Last read 12 min ago · refresh failed", so you can tell an old number from a first load still in flight. A provider that has never been read keeps the waiting line.

macOS: the new `StaleStatusMessageTests` (3) pass, and the pull request's `build-and-test` passed. The new line was checked by tests, not on screen.
