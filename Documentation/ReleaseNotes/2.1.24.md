# CodeRim 2.1.24

A macOS-only release with one change to the chat details card. Windows stays at 2.1.20.

## Chat details card

- Fast mode and Daybreak appear as a filled dot and name only while they are on. When both are off the row is gone and the card is shorter; when one is on, its name has the full width and is no longer shortened to "Fast mo…".

## Verification

macOS: full local test suite with 0 failures. The card was checked by hand in the running app on the development Mac.
