# CodeRim 2.1.40 for macOS

- Chat rows in the notch display their token totals, including sub-agent usage. The row previously received the computed total but left its label empty.
- When Codex saves an attachment preamble as a chat title, CodeRim uses the first line of the actual request as its display label. Explicit chat names keep their priority. The same label appears in token history.

## 한국어

- 노치의 메인 채팅 행에 하위 에이전트를 포함한 토큰 사용량을 표시합니다. 계산한 값을 화면에 전달하고도 빈칸으로 표시하던 문제를 수정했습니다.
- Codex가 첨부파일 안내문을 채팅 제목으로 저장한 경우 실제 요청의 첫 줄을 표시합니다. 직접 지정한 채팅 이름이 우선 적용되며, 사용량 기록에도 같은 이름을 표시합니다.
